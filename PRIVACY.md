# Privacy

Local SPL Reference records can contain richer information than this archive. The contribution DTO does not contain precise GPS coordinates, Project identifiers or names, excluded notes, excluded photos, source photo paths, Apple IDs, email addresses, contacts, or account identifiers. Only explicitly reviewed public fields are submitted. Included photos are newly rendered JPEG derivatives; client and server checks remove/reject metadata-bearing files. Server operational security logs are not part of public records.
