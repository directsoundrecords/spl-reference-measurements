# Methods

Records are stored observations from documented DSR SPL Reference sessions, not recalculated exports. A/C/Z frequency weightings and Fast/Slow/Impulse time responses retain their standard acoustical meanings. Stored LAeq/Lceq/Lzeq, maxima, minima and peak values are included only when they exist.

Quality classes are descriptive: `indicative` means no applicable stored calibration evidence; `device_calibrated` records an app/device calibration; `externally_calibrated` records an acoustic calibration path. None implies IEC Class 1/Class 2 certification or laboratory/reference-grade performance. Device, microphone, input, OS, app and analysis-method versions support interpretation.

Environment values use taxonomy version 1 canonical IDs. Public location is limited to none, city, an explicitly approved approximate area, or an explicitly approved named public place. Coordinates and private addresses are not schema fields. Phone microphones, placement, environment, overload and calibration limitations can materially affect results; records are not a substitute for a certified compliance survey.
