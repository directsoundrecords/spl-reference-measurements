# DSR SPL Reference Measurements

Open, curated real-world sound-level observations contributed through **DSR SPL Reference** and published by Direct Sound Records. Each measurement is an independent public object with canonical machine-readable JSON and a human-readable record; Projects are never public archive objects.

Public IDs use `SPL-YYYY-NNNNNN`, where the number is the reserving GitHub pull-request number and the year is the measurement completion year. Schema version: **1.0.0**. Environment taxonomy: **1**.

See [Methods](METHODS.md), [Contributing](CONTRIBUTING.md), [Privacy](PRIVACY.md), and the [schema guide](schemas/README.md). `measurement.json` is canonical; `data/measurements.csv` is a generated discovery index. All candidates are validated and curator-reviewed before merge.
